# AirSense 10 CPAP Equipment: SOP and Case Study

**Status: DRAFT. NOT APPROVED FOR CLINICAL USE.**

This is a technical writing portfolio demonstration, not an authorised hospital procedure. It must not be used as clinical or equipment-handling guidance.

## Project overview

A four-page standard operating procedure (SOP) for hospital technicians handling returned ResMed AirSense 10 CPAP equipment, accompanied by a one-page technical writing case study.

The sample demonstrates how procedural documentation can support consistent handling decisions through clear sequencing, warnings, component-routing information and record-keeping requirements.

## The documentation challenge

An equipment-handling procedure needs more than a list of actions. Readers must be able to identify when to proceed, when to stop, where different components should go and what information needs to be recorded.

The writing challenge was to make these decisions visible and easy to follow without obscuring safety-related information or assuming that every returned item follows the same path.

## My approach and skills demonstrated

- **Procedural writing:** Organised the work into clear, task-focused instructions for the intended technician audience.
- **Safety communication:** Used warnings and stop-work instructions to distinguish routine steps from conditions requiring caution.
- **Decision support:** Used component-routing tables to make handling choices easier to interpret.
- **Document control:** Included record-keeping and documentation considerations.
- **Information design:** Structured content for scanning and use at the point of work.
