# UX & UI Writing Samples

## Project overview

Product-content portfolio examples demonstrating how clear language, information hierarchy and user-focused messaging support digital experiences.

The featured sample is a landing page for Relay, a **fictional** B2B workflow automation platform for growing teams. It is a portfolio demonstration, not a live commercial product.

## The content design challenge

A landing page needs to help a visitor understand a product quickly, recognise its potential value and decide what to do next. That requires balancing concise messaging with enough information to explain features, address questions and build confidence.

The sample demonstrates decisions about the order, emphasis and purpose of different content elements, rather than treating each line of copy in isolation.

## Approach and skills demonstrated

- **Value-proposition writing:** Communicating the product's purpose and potential benefits clearly.
- **Benefit-led feature copy:** Translating product capabilities into user-relevant language.
- **Information hierarchy:** Organising content from the main proposition through supporting details.
- **Calls to action:** Writing clear prompts for the next step.
- **Reassurance and FAQ content:** Anticipating questions and reducing uncertainty.
- **Plain language and UX writing:** Keeping interface-adjacent copy concise, consistent and easy to scan.
