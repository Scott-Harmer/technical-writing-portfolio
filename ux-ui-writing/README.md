# UX & UI Writing Samples

Standalone UX writing and product-content examples created to demonstrate clear, user-focused communication for digital products.

## Relay Landing Page

A landing page for Relay, a fictional B2B workflow automation platform for growing teams.

The sample demonstrates:

- Hero and value-proposition writing
- Benefit-led feature copy
- Product messaging
- Procedural content
- Reassurance copy
- Call-to-action writing
- FAQ content
- Information hierarchy
- Plain language
