# Articulate Rise 360: E-learning Samples

## Project overview

A set of e-learning portfolio samples created in Articulate Rise 360 and tested as SCORM packages in TalentLMS. The linked PDF versions make the content easy to inspect without requiring access to an LMS.

The samples cover different learning contexts, demonstrating how instructional content can be structured around practical decisions, workplace behaviours and learner understanding.

## Learning design considerations

Developing e-learning involves more than presenting information on screen. Content must be divided into manageable steps, connected to the intended learning purpose and supported by opportunities to check understanding.

These samples demonstrate instructional sequencing, scenario-based approaches, assessment design and accessibility awareness. SCORM publishing and LMS testing are part of the documented workflow.
